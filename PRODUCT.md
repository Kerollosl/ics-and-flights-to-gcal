# Product

## Register

product

## Users

Single user (the extension author), a frequent traveler who wants ICS files turned into Google Calendar event templates with minimal friction. Used in short bursts: drop a file, glance at parsed details, open a template, then save it in Google Calendar. No onboarding, no accounts, no settings surface to speak of.

## Product Purpose

Parses `.ics` files (drag-drop or file picker), previews events locally, then opens Google Calendar intent URLs for the user to review and save. The active extension does not read Gmail or detect flight emails. No sign-in is required by the extension; event details leave the device when the user opens a calendar link. Success = fewer clicks between "calendar file exists" and "event is on my calendar."

## Brand Personality

Crisp and native — should feel like it belongs to macOS/Chrome itself, not like a third-party SaaS product bolted onto the browser. System fonts, minimal color, restrained chrome, no marketing flourishes. Utility, not identity.

## Anti-references

Keep the popup restrained: system fonts, quiet surfaces, clear actions, and limited rounding. Avoid decorative gradients or oversized branding in this short-lived utility.

## Design Principles

- **Native over branded.** Read as a system utility extension, not a startup landing page shrunk into 360px.
- **Speed over ceremony.** Every screen exists to get the user from "file selected" to "event reviewed and saved" in the fewest steps — no decorative delays or unnecessary states.
- **Trust through restraint.** The pitch is "no sign-in, nothing uploaded" — the visual design should reinforce that quietness rather than compete with it via loud color or motion.
- **One clear action per screen.** Drop zone, preview, confirm — never make the user parse competing visual weight to find the primary action.

## Accessibility & Inclusion

No specific accessibility requirements beyond sensible default contrast ratios and standard motion (no requirement to suppress animation, but nothing gratuitous either).
